# VarshaMitra — Code Raiders / SakshamVaani

**SIH 2026 · PS 086 · Hyperlocal Monsoon Intelligence**

## Run
1. Open this folder in VS Code.
2. Use Live Server on `index.html`.
3. Allow browser permissions or choose **Demo Mode**.
4. Select English, Odia or Hindi.
5. Complete the demo farmer profile.

## Highlights
- Advanced mobile-app presentation inside a responsive phone frame.
- Showcase header above the phone with Code Raiders / SakshamVaani identity and PS information.
- Hyperlocal weather dashboard with safe fallbacks so no `undefined` values appear.
- 7-day monsoon forecast.
- Crop intelligence and suitability indicators.
- AI Krishi Saathi with text + browser voice input.
- Full Odia UI mode: onboarding, dashboard, forecast, crops, AI Saathi, labels and prototype responses adapt to Odia.
- Permission Continue button remains disabled until all requested browser permissions are granted. Demo mode is separate for presentations.

## Demo data
The weather values in this prototype are demonstration values. They are not a live weather feed and should be replaced with verified API/model outputs for deployment.
